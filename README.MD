# 🎵 Spotify Clone

A pixel-perfect Spotify clone built with HTML, CSS, and Vanilla JavaScript — created as a frontend practice project.

## 🚀 Features

- 🎨 Spotify-like UI — dark theme, sidebar, navbar, music player
- ▶️ Play / Pause / Next / Previous controls
- 🔀 Shuffle & 🔁 Repeat functionality
- 📊 Progress bar — seekable
- 🔊 Volume control
- 🔍 Search songs by title or artist
- 💚 Like / Unlike songs
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Figtree)
- iTunes API / Local JSON
